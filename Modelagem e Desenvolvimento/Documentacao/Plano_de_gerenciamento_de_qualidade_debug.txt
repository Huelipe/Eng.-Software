Plano de Gerenciamento de Qualidade
Aplicativo de Controle de Finanças
Engenharia de Software
Felipe Ferrer Sorrilha, Giovanna Sanches Reghine e Pedro Miguel Lorin

1. Objetivo
Este documento apresenta o plano de gerenciamento de qualidade para o aplicativo de controle de finanças desenvolvido por três alunos da disciplina de Engenharia de Software. O objetivo é garantir que oproduto final atenda aos requisitos funcionais e não funcionais definidos, assegurando qualidade, segurança, desempenho e boa experiência do usuário.

2. Papéis e Responsabilidades
Papel == Responsabilidade
Felipe == Organização do repositório no github; integração dos códigos em um arquivo main; aplicação do padrão de projeto observer.
Giovanna == Criação das funções que criam relatórios e resumos; aplicação do padrão de projeto decorator.
Pedro == Criação das funções que atualizam o saldo e salvam os dados; aplicação do padrão de projeto facade.

3. Padrões de Documentação, Ferramentas e Desenvolvimento
Documentação:
- Uso de README.md com descrição do projeto, requisitos e instruções de uso.
- Registro de decisões e artefatos no GitHub (commits e issues).
- Organização de sprints e atividades no Trello.
Ferramentas:
- GitHub: versionamento e controle de progresso.
- Trello: gestão das tarefas e acompanhamento semanal.
- Figma: prototipação e design visual.
- Flutter ou React Native: desenvolvimento mobile multiplataforma.
- VS Code: ambiente de desenvolvimento.
Desenvolvimento:
- Código estruturado, modular e comentado.
- Revisões entre pares antes de integração.
- Testes em dispositivos Android e emuladores.
- Foco em interface responsiva e fluida.

4. Padrões Não Funcionais
Segurança: autenticação de usuários, criptografia de dados locais e validação de entrada.
Desempenho: tempo de resposta inferior a 2 segundos e uso eficiente de recursos.
Usabilidade: interface intuitiva, responsiva e coerente com práticas de UX mobile.
Confiabilidade: recuperação de falhas e mensagens de erro claras ao usuário

5. Processos de Garantia de Qualidade
- Gestão de atividades com acompanhamento no Trello.
- Revisão de código e protótipos entre os integrantes.
- Testes unitários e funcionais para validar comportamento.
- Simulação de uso por usuários finais.
- Reuniões de retrospectiva para ajustes de processo.

6. Atividades e Métricas de Qualidade
Atividade Métrica Objetivo
Revisão de código -> % de código revisado Garantir que 100% do código seja revisado
Testes funcionais -> % de funcionalidades testadas Cobrir no mínimo 80% das funcionalidades principais
Usabilidade -> % Número de falhas de navegação Reduzir inconsistências e confusão visual
Controle de erros -> % Falhas detectadas por entrega Corrigir todas as falhas críticas antes da entrega final
Documentação -> % Atualizações por sprint Manter documentação sincronizada com o desenvolvimento

7. Referências e Padrões Adotados
ISO/IEC 9126 – Qualidade de Software: define atributos como funcionalidade, confiabilidade, usabilidade, eficiência e manutenibilidade. Esses critérios orientam a avaliação da qualidade geral do aplicativo.

ISO 9001 – Gestão de Processos: usada como referência para garantir que o processo de desenvolvimento siga um ciclo de melhoria contínua, com documentação e rastreabilidade. 

CMM (Capability Maturity Model): orienta boas práticas para evolução e padronização dos processos de software, servindo como guia para manter consistência e controle.

Padrões PROCERGS de Segurança: define boas práticas nacionais de autenticação, criptografia e controle de acesso, fundamentais para a proteção dos dados dos usuários.

Sommerville (2019): referência teórica base sobre Engenharia de Software, que fundamenta a importância da qualidade, verificação e validação no ciclo de vida do software.

8. Conclusão 
O plano de gerenciamento de qualidade garante que o aplicativo de controle de finanças seja desenvolvido com foco na segurança, desempenho e experiência do usuário. A divisão equilibrada das funções entre os três integrantes e a adoção de padrões reconhecidos internacionalmente proporcionam um processo de desenvolvimento organizado e de alta qualidade
