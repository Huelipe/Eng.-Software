> main.py

Certifique-se de que as pastas Felipe, Pedro e Giovanna estão na mesma pasta que o arquivo main.py.

> main_kivy.py
Instalação das bibliotecas necessárias

Antes de executar, abra um terminal e digite os comandos abaixo para instalar as dependências:

pip install kivy
pip install kivymd==1.2.0
pip install kivy-garden
pip install matplotlib
pip install kivy-garden.matplotlib

Estrutura de pastas

Garanta que a pasta ui (além das outras) está na mesma pasta que o arquivo main_kivy.py.

Execução

Após isso, abra um terminal e execute o comando:

python3 main_kivy.py
